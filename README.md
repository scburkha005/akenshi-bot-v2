# akenshi-bot-v2
Akenshi bot is a twitch chat bot created with the intention of replicating many existing common chat bot features while also iterating on new ideas that haven't been explored yet.

## Tech Stack
Currently, Akenshi Bot is a vite SSR app using Caddy as a reverse-proxy to serve the application securely and hosted on an ec2 instance in AWS.
#### Backend
- Express
- Mongodb
- Caddy
#### Frontend
- React
- Vite
